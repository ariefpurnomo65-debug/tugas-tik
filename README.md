# LKPD Interaktif Informasi Digital (Kelas XI, Bab 1)

Kartu LKPD berbasis HTML untuk pembelajaran pengayaan Informatika. Setiap kartu (kartu1.html sampai kartu8.html) dibuka lewat QR code yang dicetak pada kartu fisik.

## Cara kerja
1. Siswa memilih satu kartu secara acak, lalu memindai QR code-nya.
2. Siswa memilih kelas (XI-1 atau XI-3).
3. Halaman menampilkan anggota kelompok yang sesuai dengan nomor kartu, lalu studi kasus dan petunjuk pencarian.

## Gambar tangkapan layar
Tambahkan gambar di folder yang sama dengan file HTML, dengan nama:
kasus1.jpg, kasus2.jpg, ..., kasus8.jpg (huruf kecil).
Jika belum ada, kotak kosong akan tampil di halaman.

## Hosting
Gunakan GitHub Pages. URL setiap kartu adalah https://<username>.github.io/<nama-repo>/kartuN.html
